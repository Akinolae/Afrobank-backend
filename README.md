# Afrobank naija

AfrobankAPI is the backend that powers the afrobank app
You get a virtual account when you register, after registering you can use the account number created to initiate transacttions.

```
clone the repo
add a .env file 

NODE_ENV=**********
DB_CONNECT=**********
TOKEN_SECRET=**********
DEFAULT_BALANCE=**********
```
```
npm install
```
```
npm run dev
```
**KEY TAKEAWAY**

1. you can recieve money (demo money)
2. you can transfer money
3. you have access to updated transactions history
4. get single updated transaction record
